# Documentation

This application builds automations on a canvas and runs them in the background
on a real cloud browser.

There are two ways to use it:

- **Hosted.** Subscribe and we run it for you. Nothing to install.
- **Self-hosted.** Run the same application yourself, free, under AGPL-3.0. No
  feature gates, no plan limits.

## Where to start

If you are self-hosting, read the [self-hosting guide](/docs/self-hosting)
first, then work through [Trigger.dev setup](/docs/trigger-dev) — workflow runs
do not work until that is done.

If you want to understand what you are building with, read the
[node reference](/docs/nodes).

If you want to understand how it fits together, read the
[architecture overview](/docs/architecture).
